# 토지피복 변화와 구역 통계

상태 `TESTED_SYNTHETIC`. 동일 격자의 합성 연차 GeoTIFF에서 실제 계산기로 전이행렬, 변화 집계, 변화 집중지역, 구역별 통계를 재현했다. 실제 KLHK 연차자료의 사용 승인과 독립 정확도 검증은 별도 절차로 기록한다.

## 입력 자료

| 입력 | 검사 |
|---|---|
| `RasterPin` 두 개 | 서로 다른 순서의 관측 연도·파일 SHA-256, 동일 분류체계 SHA와 자료 유형, 버전·데이터셋 식별자 |
| 연차 GeoTIFF | 정수 1밴드, 미터 단위 등적 투영과 북향 격자, 같은 CRS·크기·해상도·원점, 명시한 NoData |
| 원본 메타데이터 | `observed_on`, `taxonomy_sha256`, `source_kind` 태그를 입력 핀과 대조. `dataset_id`와 `version` 태그도 있을 때 대조 |
| `MaskPin` 선택 | 독립 SHA-256, 같은 격자와 이진 품질값. 1 유효, 0 제외 |
| `ZonePin` 선택 | GeoJSON 파일 SHA-256과 경계 버전, CRS84 Polygon 또는 MultiPolygon, 중복 없는 ID와 이름 |
| 의미 그룹 선택 | 산림 및 시가지에 포함할 클래스 코드 목록. 두 그룹은 중복될 수 없으며 정의하지 않은 그룹 지표는 미산출 |

분석기는 해시를 검증한 GeoTIFF 바이트에서 읽는다. 외부 사이드카를 읽을 때 달라질 수 있는 마스크는 별도 `MaskPin`으로 관리한다. 두 연도에 같은 내용의 파일을 재사용하거나 태그의 관측일을 바꾸지 않고 요청일만 바꾼 경우 계산을 중단한다. 공식 참조·모델 예측·연구용 참조·합성 예제별로 두 연도의 유형을 맞춘다. 공식 사용 승인과 계산용 자료의 출처 판단은 상위 등록 절차에서 확인한다.

2021년 WorldCover를 조회할 때 실제 관측 연도를 유지해야 한다. 다른 해의 자산이 없으면 두 시점 분석에 사용하지 않는다.

## 계산 기준

- 픽셀 면적은 북향 등적 투영의 픽셀 가로 길이와 세로 길이를 곱한 뒤 10,000으로 나눈 헥타르다. 경위도 격자나 Web Mercator 등에서 동일 면적을 가정하지 않는다. 격자가 다르면 상위 처리 단계에서 범주형 최근린 재투영을 검증해 별도 출처와 SHA를 등록한다.
- 양쪽 자료의 내부 마스크, NoData, 분류체계의 품질 코드와 명시한 외부 마스크를 반영한 교집합을 전이 분석 면적으로 사용한다. KLHK 코드 `2500` Awan은 분류체계에 보존하고 토지피복 통계에서 제외한다. 미등록 유효 코드는 오류를 발생시킨다. 유효 면적의 교집합이 없으면 비교를 차단한다.
- 전이행렬의 행은 이전 클래스, 열은 이후 클래스다. 대각선은 유지 면적, 비대각선은 전이 면적이다. 셀 전체의 합은 공통 유효 면적과 같다. 클래스별 총증가·총감소·순증감을 같은 지지범위에서 계산하고, 연도별 전체 유효 면적은 별도 필드에 남긴다.
- 산림 감소는 등록한 산림 그룹에서 그룹 밖으로 이동한 면적이다. 시가지 확대는 등록한 시가지 그룹에 외부에서 들어온 면적이다. 그룹 내부 클래스 변경은 그룹 지표에 중복 집계하지 않는다.
- 변화 집중지역은 변한 픽셀들의 상하좌우 4방향 연결 요소다. 최소 픽셀 수 미달 요소의 픽셀 수를 별도로 기록한다. 통계적 유의성이나 신뢰확률은 산출하지 않는다.
- 구역별 통계는 폴리곤에 중심이 들어오는 픽셀을 집계한다. 좁은 경계와 유역·군·계획구역의 중복은 각 경계의 해상도와 범위를 함께 해석한다. 픽셀이 겹치는 구역의 면적은 서로 합산하지 않는다. 유효 픽셀이 없는 구역의 변화율은 미산출 상태다.

## 결과 연결

`analyze_change(earlier, later, taxonomy, zones=..., forest_codes=..., settlement_codes=...)`가 계산 결과를 반환한다. `write_change_assets(result, directory)`는 기존 파일을 덮어쓰지 않고 다음 세 산출물을 기록한다.

| 산출물 | 사용 |
|---|---|
| `report.json` | 관측 연도별 원본 SHA, 분류코드, 공통 유효 면적, 연도별 클래스, 전이행렬, 증감, 구역별 계산 및 결과 등록 근거 |
| `hotspots.geojson` | CRS84 변화 요소, 픽셀 수, 면적. 변화가 없으면 빈 FeatureCollection |
| `transition.tif` | 원래 등적 격자의 uint16 전이 코드. 0은 NoData, 나머지는 `1 + 이전 클래스 인덱스 × 클래스 수 + 이후 클래스 인덱스` |

기존 결과 카탈로그는 패키지별 공간 CRS 하나를 적용한다. CRS84 지도에 집중지역을 등록하면 등적 투영의 GeoTIFF는 별도 자산 링크로 연결할 수 있다. 연차 지도 원본과 양쪽 출처·분류체계는 하나의 결과 ID 및 명시적 증거 핀에 결속한다.

## 재현 시험

```powershell
python -X utf8 -m pytest -q tests/lcluc/test_change.py
```

합성 고정 격자는 공통 유효 7헥타르와 전이 4헥타르를 포함한다. 시험은 행렬 합과 클래스 증감, 산림 감소·시가지 확대, 연결 요소, 구역 집계, 해시·날짜·격자 오류와 자료 없음 처리를 확인한다.

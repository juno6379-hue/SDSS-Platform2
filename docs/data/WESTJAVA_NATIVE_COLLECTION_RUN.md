## 수집과 실패 복구

수집 진입점은 `services.datahub.westjava_native`다. 수집기는 기존 Sentinel의 실행 및 코디네이터 잠금을 공유한다. 별도 디렉터리의 승인 기록과 진행 원장이 전역 장면을 추적한다. 연도 오름차순으로 Sentinel-2와 Landsat 배치를 실행한다. Sentinel-2는 여섯 반사도 밴드와 SCL 및 L2A 제품 XML을, Landsat은 여섯 반사도 밴드와 QA_PIXEL·QA_RADSAT를 각각 보존한다. 재실행은 같은 ETag·길이의 부분 파일 경계에서 재개하고 완료된 파일은 원본 해시를 검증한다.

첫 병렬 HEAD 점검에서 429가 발생했다. 원격 영상 본문 요청은 0건이었다. 공급 서명 캐시를 공유하고 HEAD 시작 간격을 조정한 뒤 22:29 KST 배치를 다시 시작했다. HTTP 429 재발 시 새 요청을 중단하고 공급자 대기 지시를 진행 원장에 기록한다. 과거 원장·원본은 별도로 보존한다.

2020년의 실제 HEAD 합계는 Sentinel-2 11장면 8,401,060,705바이트, Landsat 4장면 2,027,444,484바이트다. Sentinel-2 원본 수신이 먼저 진행 중이다. Landsat은 같은 연도의 Sentinel-2 배치가 종료되면 이어서 시작한다. [실행 로그](../../evidence/westjava/native-collection-runtime/collector.stdout.log)

첫 신규 Sentinel-2 장면 `T48MZT`의 6밴드·SCL·제품 XML과 원본 해시를 검증했다. 실제 원본에서 10m 반사도 모자이크를 생성하고 시험창 35,153픽셀 중 맑은 28,448픽셀을 얻었다. 물리 피복은 시험창 내 100%, 구름 제거 후 적격은 80.93%다. 연차 배치 자동 학습은 해당 연도의 전체 수집 완료 영수증을 기다린다. [첫 장면 전처리 근거](../../evidence/westjava/native-collection-runtime/first-new-sentinel-scene-qc.json)

## 완료 영수증 라우팅

정상 종료된 연차 센서 배치는 `data/raw/explorer/province/west-java-optical/native/<sensor>/<year>/batch-complete.json`을 원자적으로 발행한다. 배치는 승인 SHA, 전체 바이트, 장면별 원본·출처·ETag 해시를 담는다. 백그라운드 지역 워커는 새 완료 영수증을 감지해 중복 입고를 막고 센서별 고정 연구 창을 생성한다. Sentinel-2는 XML의 제품 ID와 반사도 변환을 적용한다. Landsat은 포화 플래그를 품질 마스크에 포함한다. [Copernicus 제품 계약](https://sentiwiki.copernicus.eu/web/s2-products)

연도별 학습은 같은 연도에 속하고 장면·관측일·공간이 분리된 train/validation/test 입력을 확보했을 때 실행한다. 실증용 구역의 동년 Esri 결과는 약한 참조 일치도다. 새 전체 장면 수집 범위와 별개로 모델 시험 범위는 선택된 연구 창으로 기록한다. 런타임은 독립 검증과 과학·운영 승인이 없어 자동으로 운영 배포에 접근하지 않는다. 독립 과학 정확도와 실제 운영 승인은 별도 시스템에서 기록한다.

진행 파일은 `data/raw/explorer/province/west-java-optical/native/progress.json`, 작업 로그와 PID는 [실행 근거](../../evidence/westjava/native-collection-runtime/)에 있다.
